# emstime


Setup: (Arch)
- Must have Python and Node installed
- Install UV with `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Install Pebble SDK with `uv tool install pebble-tool --python 3.13`

Build and Run:
- `pebble build`
- `pebble install --emulator basalt`

aplite - OG Pebble / Pebble Steel
basalt - OG Pebble Time
chalk - Pebble Time Round
diorite - Pebble 2
emery - Pebble Time 2
flint - Pebble 2 Duo
gabbro - Pebble Round 2
